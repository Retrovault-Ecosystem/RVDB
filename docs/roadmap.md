# RetroVault Database Roadmap

## Phase 1 — RVDB Foundation

Status: IN PROGRESS

Completed:

- YAML entity storage system
- Entity loader architecture
- Entity object abstraction
- Relationship graph engine
- Reverse relationship indexing
- Relationship resolver
- Schema validation system
- Relationship validation system
- CLI framework
- Entity querying
- Entity searching
- Core/platform relationship handling
- Build pipeline foundation


## Phase 2 — Expand RVDB Entity Coverage

Goal:

Build a complete structured metadata database for retro gaming systems.

Add:

- Complete platform database
- Complete emulator database
- Complete Libretro core database
- Developer database
- Publisher database
- Genre database
- Controller database
- BIOS database
- Shader database
- Overlay database
- Theme database


## Phase 3 — RetroVault Application Integration

Goal:

Connect RVDB with the RetroVault application.

Features:

- Platform browsing
- Game library management
- Emulator configuration
- Core selection
- Shader selection
- Overlay selection
- Theme management
- Controller profiles
- Metadata display
